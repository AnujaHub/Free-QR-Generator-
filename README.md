# QR Code Generator

A responsive QR Code Generator built using HTML, CSS and JavaScript.

## Features
- Generate QR codes instantly
- Download QR as PNG
- Print QR codes
- Share QR directly
- Persistent QR state using localStorage
- Keyboard shortcuts
- QR color customization
- Responsive mobile-friendly UI

## Tech Stack
- HTML5
- CSS3
- JavaScript
- QRCode.js

## Keyboard Shortcuts
- Enter → Generate QR
- Esc → Clear QR
- Ctrl/Cmd + S → Download
- Ctrl/Cmd + P → Print
